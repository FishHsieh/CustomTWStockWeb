# 股市追蹤網站

從你 Google 試算表「殖利率」檔案裡「標兵」分頁 **欄位U（代號欄）整欄**整理出的股票/ETF清單（252檔個股 + 88檔ETF，共340檔），
自動抓取 K線、EPS趨勢、配息殖利率、月營收年增率，做成一個網頁儀表板。另外有黃金/原油/美債10年期殖利率/台股大盤的總經趨勢面板。

## 怎麼用

### 1. 更新資料

雙擊 **`更新資料.bat`**。

第一次執行要抓 340 檔的資料，會超過 FinMind 每小時 600 次的額度，**需要分兩次跑**：
第一次跑到一半會顯示「額度用完了」然後停住（已經抓到的都會留著、網站看得到），
等大約一小時之後再雙擊一次，就會接著把剩下的補完。

之後的日常更新：收盤價、個別三大法人、月營收都改由 TWSE／TPEx 官方全市場端點各抓一次，再寫入 340 檔資料；
其中個別三大法人只剩 6 檔興櫃須用 FinMind，另有少量全市場資料；台指期未平倉也改由 TAIFEX 官方端點更新日期相同的最新值，通常約 **10 次**，不會超過免費會員每小時 600 次的額度。
官方端點暫時失敗或新標的缺少歷史資料時，程式才會自動回退使用 FinMind。

配息/EPS 這些慢速資料不是每天重抓，而且到期日有依代號打散、不會集中在同一天；
月營收則改為官方全市場端點。到期日的實際 FinMind 請求數取決於當天哪些快取需要更新。
程式每次跑都會自動判斷哪些資料有新的、只補抓那些，其餘沿用快取；
所以同一天內重複跑第二次、第三次，都只要幾十秒。

#### 什麼時候跑最好？各種資料的公布時間

台股每一種資料公布的時間不一樣，**建議晚上再跑**，一次就能把當天的資料全部拿齊：

| 資料 | 大約什麼時候才抓得到（台北時間） |
| --- | --- |
| 上市(twse)個股/ETF 收盤價 | 收盤後 14:00 前後 |
| **上櫃(tpex)個股/ETF 收盤價** | 比上市晚，下午較晚才進得來（櫃買個股、債券ETF 都算上櫃） |
| **三大法人買賣超**（個股、全市場） | 證交所盤後約 15:30~16:00 公布，FinMind 再慢一點，**下午4點以後**才抓得到 |
| 台指期三大法人未平倉 | [TAIFEX 官方 OpenAPI](https://openapi.taifex.com.tw/) 盤後公布，大致同一個時段；官方日期落後時沿用 FinMind 最新值 |
| 月營收 | 每月10日前公布上個月的 |
| 季EPS | 依財報公布期程，一季一次 |
| 美債10年期殖利率 | 看美股，台灣時間**隔天凌晨**才會有當天的值（所以白天看到的是前一個交易日，這是正常的） |
| 黃金、原油、美元/台幣 | 幾乎24小時交易，隨時都是最新的 |

所以**下午2點多跑**的話，上市股價抓得到，但上櫃股價和三大法人還沒公布，
就會出現「更新時間是今天，可是三大法人停在上一個交易日」的情況。

不過就算跑早了也不用自己處理：程式每次跑會先讀 TWSE／TPEx 官方日成交資料，並以其實際公布日期比對快取；
個別三大法人則同樣由 TWSE／TPEx 官方端點的實際公布進度比對（興櫃才由 FinMind 備援）。**該更新的自動重抓、已經最新的才沿用快取**
（不是用寫死的時間表，所以颱風假、補班、連假這些日子也不會判斷錯）。
下午跑過一次、晚上再跑一次，第二次就只會補抓下午還沒公布的那些，很快。

網站上方也會同時顯示「資料更新時間」和「資料日期」（收盤價到哪天、三大法人到哪天），
一眼就看得出來現在看到的是不是最新的。上市和上櫃如果不同天，會分開標，例如
`（資料日期：收盤價 上市 2026-09-22／上櫃 2026-09-21、三大法人 2026-09-21）`。

至於不是天天變的那幾項，快取時效是以「天」計的，不會每次跑都重抓
（這幾項加起來約350次API，每天重抓很容易撞到 600次/小時的上限）：

| 資料 | 多久重抓一次 |
| --- | --- |
| 配息紀錄 | 7 天 |
| 月營收 | 平常 7 天；每月 1~15 號（公布期）縮成 1 天 |
| 季EPS | 平常 14 天；3、5、8、11 月（財報公布期）縮成 2 天 |
| 中文名稱對照 | 7 天 |

省下來的 FinMind 額度會留給興櫃法人、全市場指標與尚未替換的慢速資料。

### 2. 看網站

雙擊 **`開啟網站.bat`**，它會自動開瀏覽器並顯示網站（**不要直接雙擊 `index.html`**，Chrome 瀏覽器對於直接打開本機檔案會擋掉網站讀取資料的動作，一定要用這個 bat 檔開）。
看完之後，那個黑色的命令視窗留著沒關係，關掉它網站才會停止；下次要看，再雙擊一次 `開啟網站.bat` 即可。

## 網站看得到什麼

- **總經面板**：黃金、原油(WTI)、美債10年期殖利率、台股加權指數、美元/台幣，各自顯示近一年走勢小圖與漲跌幅。
- **還原K線**：K線圖標題旁邊有一顆 **`還原K線`** 按鈕。
  除權息和股票分割會讓股價出現「假的斷層」（例如 0050 在 2025-06-18 從 188 元變成 47 元，那是1股分割成4股，不是真的跌了75%），
  斷層會讓均線接下來一整年都失真。按下去就會把斷層前的歷史價按比例還原，整條線可以直接比較；
  最新一天維持真實市價不動（前復權）。按鈕旁邊會顯示這檔還原了幾次、是除權息還是分割。
  選擇會記住，下次打開還是同一個模式。
  注意：**成交量不會跟著還原**（顯示的是當天實際成交幾張，還原模式下標上 `*`），
  所以分割前後的成交量張數不能直接比大小。
- **K線圖操作**：滑鼠在K線圖上左右移動時，上方會顯示**那一天**的日期、開高低收、漲跌、成交量，
  均線圖例也會跟著換成那天的均線值；同時圖上會有一條虛線**自動對到那天的收盤價**，右邊價格軸上直接標出價格。
  （水平線是貼著當天收盤價，不是跟著滑鼠高度飄，所以滑鼠上下移動不影響讀數。）滑出圖表就回到最新一天。
- **個股 (252檔)**：卡片顯示現價、殖利率、最新月營收年增率；點進去看K線圖（含10日線、月線、季線、年線）、季EPS趨勢圖、月營收年增率(YoY)/月增率(MoM)長條圖、近期配息紀錄（含除息前收盤價、除息參考價）。
- **ETF (88檔，含槓桿/反向/債券ETF)**：卡片顯示現價、殖利率；點進去看K線圖（同樣有4條均線）和配息紀錄（同樣有除息參考價；ETF沒有EPS和月營收，這兩項不適用）。
- 上方可以搜尋代號/名稱，也可以切換排序（依殖利率、依月營收YoY）。

## 如果之後想改追蹤清單

清單放在 **`scripts\watchlist.txt`**，一行一個代號、`#` 後面是註解，直接用記事本改就好（不用動程式）。
它是從 Google 試算表「標兵」分頁的**欄位U（代號欄）整欄**擷取出來的，不限列數。

> 之前這份清單是直接寫死在 `build_tickers.py` 裡，而且只抄了「前200列」，
> 所以第200列之後的代號（例如 U244 的 3661 世芯-KY）全部被漏掉。
> 現在改成讀 `watchlist.txt`，而且擷取時已確認：標兵分頁 513 欄全部掃過，
> 只有欄位U 是代號清單（AB上次標價/AE現價/AD最高買價/AL模擬價格 那些四位數是「價格」不是代號）。

改完 `watchlist.txt` 之後執行：

```
python scripts\build_tickers.py
```

再雙擊 `更新資料.bat` 重新抓一次。
