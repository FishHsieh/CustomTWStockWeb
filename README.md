# 股市追蹤網站

從你 Google 試算表「殖利率」檔案裡「標兵」分頁前200列整理出的股票/ETF清單（95檔個股 + 61檔ETF），
自動抓取 K線、EPS趨勢、配息殖利率、月營收年增率，做成一個網頁儀表板。另外有黃金/原油/美債10年期殖利率/台股大盤的總經趨勢面板。

## 怎麼用

### 1. 更新資料

雙擊 **`更新資料.bat`**。

第一次執行會抓約 150 幾檔股票的資料，需要 5~10 分鐘，過程會顯示進度，跑完視窗會停住等你按任意鍵。
之後如果只是想更新最新報價，直接再雙擊一次就好（20小時內抓過的資料會用快取，跑起來會快很多）。

### 2. 看網站

雙擊 **`開啟網站.bat`**，它會自動開瀏覽器並顯示網站（**不要直接雙擊 `index.html`**，Chrome 瀏覽器對於直接打開本機檔案會擋掉網站讀取資料的動作，一定要用這個 bat 檔開）。
看完之後，那個黑色的命令視窗留著沒關係，關掉它網站才會停止；下次要看，再雙擊一次 `開啟網站.bat` 即可。

## 網站看得到什麼

- **總經面板**：黃金、原油(WTI)、美債10年期殖利率、台股加權指數、美元/台幣，各自顯示近一年走勢小圖與漲跌幅。
- **個股 (95檔)**：卡片顯示現價、殖利率、最新月營收年增率；點進去看K線圖（含10日線、月線、季線、年線）、季EPS趨勢圖、月營收年增率(YoY)/月增率(MoM)長條圖、近期配息紀錄（含除息前收盤價、除息參考價）。
- **ETF (61檔，含槓桿/反向/債券ETF)**：卡片顯示現價、殖利率；點進去看K線圖（同樣有4條均線）和配息紀錄（同樣有除息參考價；ETF沒有EPS和月營收，這兩項不適用）。
- 上方可以搜尋代號/名稱，也可以切換排序（依殖利率、依月營收YoY）。

## 資料來源

- 股價K線、配息紀錄、月營收、季EPS：[FinMind](https://finmindtrade.com)（涵蓋上市+上櫃）
- 黃金/原油/美債殖利率/大盤/匯率：Yahoo Finance

僅供參考，不構成投資建議，報價可能有延遲。

## 申請 FinMind API Token（加大資料額度，遇到卡住時用）

FinMind 免費/匿名額度是 300 次/小時，這個網站一次要跑約 500 次 API，可能會卡住、要分兩次才抓得完。
你的帳號 `vinsonhsieh61@gmail.com` 已經是 FinMind 註冊會員（600次/小時），對應的 Token 已經幫你存在
`scripts\finmind_token.txt` 裡了，`更新資料.bat` 會自動使用，不用再做任何事。

如果之後 Token 失效或想換一組：
1. 登入 <https://finmindtrade.com/analysis/#/account/user>
2. 那頁「api token 金鑰」欄位就是你的 Token，按旁邊「複製」
3. 貼到 `scripts\finmind_token.txt`（取代裡面舊的那一行），存檔
4. 重新雙擊 `更新資料.bat`

這個檔案是你的個人金鑰，不要分享給別人、也不要上傳到公開的地方。

## 如果之後想改追蹤清單

目前的清單是從 Google 試算表「標兵」分頁前200列手動整理出來的（因為那份表格排版很複雜，欄位混雜著大盤指數、個股、ETF、外國股票）。
如果之後清單有變動，要更新 `scripts\build_tickers.py` 裡的 `RAW_ROWS`，再重新執行：

```
python scripts\build_tickers.py
```

再雙擊 `更新資料.bat` 重新抓一次。
